# Программное обеспечение «Софт386» — абсолютно новый, публичный Электронный каталог с маркировками (Иноагенты) и (Наркотические упоминания, 224-ФЗ)

Добро пожаловать в репозиторий проекта **Программное обеспечение «Софт386»**!  

Это новые 4 АРМ и веб-интерфейс для создания нового электронного каталога с маркировками (Иноагенты) и (Наркотические упоминания, 224-ФЗ).  
Не заменяет базовую АБИС (например, **ИРБИС 64+**), а работает как дополнительное ПО в библиотеке, импортируя базы данных книги и статьи через файлы XML выгрузки от Ирбис 64+.  

📌 Важное примечание: На данном этапе разработки проект представляет собой экосистему новых 4 АРМ и электронного каталога.  
📌 Программа не содержит модулей комплектования и первичной каталогизации.  
📌 Для полноценной работы ПО «Софт386» требуется наличие в учреждении АБИС ИРБИС 64+  
📌 Для ввода в эксплуатацию в библиотеке требуется утверждение внутренним приказом учреждения.  

### 🚀 Главная фишка проекта
Современный адаптивный каталог на **PHP + MySQL**, который работает через файлы XML выгрузки вашей старой библиотечной базой и помогает закрыть требования законов РФ по маркировке (Иноагенты) и (Наркотические упоминания, 224-ФЗ).  
Вы можете выгрузить данные из ИРБИС 64+ в формате XML, развернуть локальный веб-сервер и получить современный, быстрый и красивый электронный каталог на базе связки **PHP + MySQL (OpenServer)**.  

**💼 Юридическая чистота для госучреждений:** 
В библиотеке можно абсолютно легально использовать Программное обеспечение «Софт386» (например, «ИРБИС 64+» для внутренней каталогизации, а «Софт386» — как публичный электронный каталог с маркировками), просто утвердив это внутренним **приказом руководства учреждения**. 
Выгрузка данных в формат XML — это стандартное требование ГОСТ по интероперабельности и открытости данных. Библиотека имеет полное законное право использовать эти xml-файлы.

## 📦 Что входит в комплект?
1. **Электронный каталог** — красивый, быстрый и адаптивный веб-интерфейс для читателей. Позволяет искать книги и статьи со смартфонов и компьютеров. Встроен модуль умной маркировки и защиты детей (ФЗ-436, ФЗ-224), двухпрофильная система контроля доступа к контенту (Junior / Adult) с автоматическим скрытием аннотаций в детском режиме для всех материалов с маркировкой. 
2. **Набор 4 АРМ** — готовые программы для автоматизации внутренних процессов библиотеки (включая **АРМ Библиотекаря** с книговыдачей, **АРМ Маркировка** для добавления списков иноагентов и маркеров ФЗ-224,  **АРМ Читателя (Книги)** для поиска книг, **АРМ Читателя (Статьи)** для поиска статей). В АРМ Читателя встроен модуль умной маркировки и защиты детей (ФЗ-436, ФЗ-224), двухпрофильная система контроля доступа к контенту (Junior / Adult) с автоматическим скрытием аннотаций в детском режиме для всех материалов с маркировкой. 
3. **Скрипты миграции** — готовые python-скрипты для парсинга и импорта файлов `book.xml` и `paper.xml`. 
4. **Скрипты для поддержки sql-базы в актуальном состоянии** — готовые python-скрипты для парсинга и импорта обновлённых файлов `book.xml` и `paper.xml`. Нужны при поступлении новых книг в библиотеку (add_only_new_books.py), или при списании книг в библиотеке (remove_only_missing_books.py). 
5. **Готовая структура БД** — преднастроенные схемы SQL для phpMyAdmin под разные сценарии развертывания.

* **Образец 2 (Наркотические упоминания, 224-ФЗ):** 
  > *⚠️ 18+ 224-ФЗ. НЕЗАКОННОЕ ПОТРЕБЛЕНИЕ НАРКОТИЧЕСКИХ СРЕДСТВ, ПСИХОТРОПНЫХ ВЕЩЕСТВ, ИХ АНАЛОГОВ ПРИЧИНЯЕТ ВРЕД ЗДОРОВЬЮ, ИХ НЕЗАКОННЫЙ ОБОРОТ ЗАПРЕЩЕН И ВЛЕЧЕТ УСТАНОВЛЕННУЮ ЗАКОНОДАТЕЛЬСТВОМ ОТВЕТСТВЕННОСТЬ.*

Обязанность по актуализации данных:  
В связи с регулярным обновлением реестров профильными ведомствами, администратор библиотеки обязан проверить и актуализировать эти таблицы.  
Вы можете дополнить базу или полностью очистить таблицы через phpMyAdmin.  
Ответственность за соответствие маркировок законам РФ лежит на учреждении.

### 🧔 Умный контроль выдачи в АРМ Библиотекаря

Для работы со взрослым контентом и надежного предотвращения нарушений в АРМ Библиотекаря при выдаче книг, в систему встроена сквозная проверка возраста:

1. **Регистрация пользователей:** Все читатели сначала регистрируются в **АРМ Библиотекаря** с указанием ФИО, номера телефона и точного возраста (при сомнениях сотрудник проверяет паспорт). Читателю присваивается уникальный номер билета.
2. **Безопасная выдача на абонементе:** При выдаче книги сотрудник вводит в систему номер билета и инвентарный номер книги. Программа мгновенно сверяет возраст читателя и наличие маркировки у книги:
   * **Если читатель взрослый (18+):** Всплывает бдительное уведомление о том, что книга содержит маркировку (Иноагент или ФЗ-224). Это напоминает библиотекарю проверить наличие физической наклейки на самой книге. После этого выдача успешно подтверждается.
   * **Если читателю нет 18 лет:** Система жестко блокирует операцию, выводит предупреждение о запрете выдачи несовершеннолетнему и закрывает окно. Ошибка по невнимательности здесь полностью исключена.
3. **Контроль и учет:** Все успешные выдачи фиксируются в базе данных и удобно отображаются в специальной вкладке **«Выданные книги»** в АРМ Библиотекаря.

## 🛡️ Безопасность и цензура: Модуль маркировки и двухпрофильный режим (Junior / Adult)

В систему встроен жесткий контроль соответствия законодательству РФ (Защита детей от вредоносной информации, законы об иноагентах и ФЗ-224). Карточки с особым контентом автоматически помечаются крупными яркими плашками на красном фоне:
* **Иноагенты:** *18+ ИНОАГЕНТ. НАСТОЯЩИЙ МАТЕРИАЛ...*
* **Наркотические упоминания (224-ФЗ):** *⚠️ 18+ 224-ФЗ. НЕЗАКОННОЕ ПОТРЕБЛЕНИЕ...*

### 🧒 Профиль Junior (Детский режим) — работает по умолчанию
Как на сайте Электронного каталога, так и в локальном АРМ Читателя, базовым является профиль **Junior**. В этом режиме пользователи могут видеть только базовые данные книг. **Подробное описание и аннотации для книг с маркировками 18+ ИНОАГЕНТ или 18+ 224-ФЗ полностью скрыты и недоступны для просмотра.**

### 🧔 Профиль Adult (Взрослый режим) — просмотр аннотаций 18+
Для получения доступа к полным описаниям и аннотациям совершеннолетний пользователь должен пройти верификацию. Реализовано два гениальных сценария:

1. **На сайте Электронного каталога (удаленно):**
   * Читатель заводит в библиотеке классический читательский билет, указав свое имя, дату рождения (возраст) и номер телефона.
   * Для перехода в режим `Adult` на сайте, пользователь вводит **номер своего читательского билета** и **последние 4 цифры номера телефона**.
   * Система проверяет по базе данных, исполнилось ли пользователю полных 18 лет. Если да — режим успешно переключается. Если нет — доступ строго блокируется.

2. **В локальном АРМ Читателя (на терминале в зале библиотеки):**
   * Программа на ПК в зале всегда запущена в режиме `Junior`.
   * Чтобы переключить терминал в режим `Adult`, читатель обращается к библиотекарю. Сотрудник визуально или по паспорту убеждается, что посетителю есть 18 лет, и вводит **специальный административный пароль**.
   * **Умный таймер бездействия:** Если читатель изучил книгу 18+ и ушел, оставив терминал открытым, программа автоматически переключится обратно в безопасный детский режим `Junior` ровно через **30 минут отсутствия активности**.
   * **Сброс таймера при работе:** Система отслеживает действия. Если пользователь отвлекся, таймер отсчитал, например, 20 минут (осталось 10 до сброса), но читатель снова начал искать информацию — **таймер автоматически обнуляется обратно до 30 минут**, не мешая работе взрослого посетителя.

**❗️ Дисклеймер для администраторов библиотеки:** 
Несмотря на то, что в базе есть предустановленные демонстрационные списки иноагентов и маркеров ФЗ-224, **после установки системы вы обязаны заново проверить актуальность всех данных!** Вы можете полностью очистить эти таблицы через phpMyAdmin и загрузить/ввести свой собственный актуальный список авторов и книг для обеих маркировок.
Антивирусные программы могут ругаться на исполняемые файлы (`.exe`) из-за отсутствия коммерческой цифровой подписи разработчика. Это стандартное поведение защитников Windows для самописного софта. Пожалуйста, добавьте программу в исключения вашего антивируса при установке.

## ⚙️ Пошаговая инструкция по развертыванию

### Шаг 1. Экспорт данных из ИРБИС 64+
Выгрузите актуальную базу данных книг и статей из вашей текущей АБИС ИРБИС 64+. На выходе вы должны получить два файла:
* `book.xml` — база данных книг.
* `paper.xml` — база данных статей.

### Шаг 2. Подготовка веб-сервера (OpenServer)
1. Скачайте и установите локальный сервер **OpenServer**.
2. Выполните стандартную настройку модулей (Apache/Nginx + PHP + MySQL).
3. Откройте **phpMyAdmin**, задайте надежные пароли для администратора БД (`root`).

### Шаг 3. Создание и инициализация базы данных
1. В phpMyAdmin создайте новую пустую базу данных (например, с именем `libraryan`).
2. Перейдите во вкладку «Импорт» и выберите один из 4-х доступных вариантов готовой структуры из папки `/sql`:
   * `libraryan_standard.sql` — стандартный быстрый импорт (только структура).
   * `libraryan_create.sql` — с флагом `CREATE TABLE`.
   * `libraryan_create_drop.sql` — с флагами `CREATE TABLE` и `DROP TABLE` (для чистой перезаписи).
   * `libraryan_drop.sql` — только с флагом `DROP TABLE`.

### Шаг 4. Импорт данных XML в MySQL
1. Поместите ваши файлы `book.xml` и `paper.xml` в папку со скриптами импорта.
2. Запустите скрипты парсинга через консоль. Скрипты автоматически обработают теги XML и наполнят таблицы вашей базы данных `libraryan`.
*(Примечание: Если структура ваших XML отличается от стандартной, вы можете легко отредактировать исходный код python-скриптов под свои теги).*

### Шаг 5. Размещение и настройка Электронного каталога и АРМ
1. Перенесите АРМ Библиотекаря и АРМ Читателя например в раздел жёсткого диска С:\ создав там папку libraryan. PHP-файлы электронного каталога перенесите в рабочую директорию вашего домена на OpenServer (например, `domains/web.local`).
2. Откройте php-исходники и найдите там строки конфигурации и укажите:
   * Данные для подключения к БД (хост, имя БД, логин и пароль).
   * Пароль библиотекаря для АРМ Библиотекаря и АРМ Читателя (пароль для перехода в взрослый режим Adult).
   * Время таймаута бездействия (по умолчанию 30 минут).
3. Перезапустите OpenServer, откройте сайт в браузере и проверьте корректность отображения книг, статей и работу поиска. 
 
🔑 Безопасность: В целях безопасности во всех конфигурационных файлах реальные пароли подключения к БД заменены на демонстрационные заглушки. Перед запуском укажите свои доступы.
